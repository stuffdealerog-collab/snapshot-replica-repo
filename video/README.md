# НАСЛЕДНИКИ — видеоэссе в формате motion design

Ролик проверяет гипотезу автора канала: «Нейросети и андроиды — наша новая веха развития, и, возможно, в будущем они будут жить вместо нас».

- Язык: русский.
- Хронометраж: 7:27.
- Формат: 1920×1080, 30 к/с.
- Звук: стерео, нормализован до −14 LUFS.

Готовые файлы:
- `out/naslednik.mp4` — мастер, 1080p, ≈5,5 Мбит/с; в git не хранится из-за размера, пересобирается через `render_all.sh`;
- `out/naslednik_preview_720p.mp4` — облегчённая версия, 40 МБ;
- `out/subtitles.srt` — субтитры;
- `research/sources.md` — источники и проверка фактов;
- `youtube.md` — название, описание, главы.

## Концепция

**Идея.** Ролик построен как дело о гипотезе: архивная папка, в которой машина проверяет мысль человека. Рассказчик открыто синтетический. В начале он признаётся: «я не только следователь, я — улика». Сам ролик, собранный нейросетями по одной фразе, — вещественное доказательство «новой вехи». Сформулировал вопрос при этом человек. Финальная мысль ролика держится на этом противоречии.

**Драматургия.** Три слова гипотезы стали тремя главами:
1. **ВЕХА** — история жизни как история носителей информации. Опора — теория больших эволюционных переходов (Мейнард Смит и Сатмари, 1995; Сатмари и соавторы, PNAS 2026).
2. **ЖИТЬ** — определение жизни, зависимость ИИ от людей, сознание.
3. **ВМЕСТО** — три пути: катастрофа, тихое отстранение, «передать эстафету».

Поворот даёт митохондрия. Большие переходы не заменяли старых носителей, а сливались с ними, и одна из сторон теряла автономию. Отсюда переформулировка: вопрос не в том, будут ли машины жить вместо нас, а в том, **кто станет чьей митохондрией**. Финальный вердикт выносится по каждой части гипотезы отдельно.

**Визуальный язык.** Архивное дело и естественнонаучный атлас XIX века:
- бумага, тушь, штампы, каталожные карточки;
- рисунки собраны из точек, как гравюра-стиплинг;
- одни и те же 7 000 точек перетекают через всех «носителей»: ДНК → клетка → колония → нейрон → речь → глиняная табличка → книга → чип → нейросеть. Так в кадре видна сама мысль ролика: информация одна, носители меняются;
- машинные пометки на полях — синим моноширинным шрифтом, это голос самого рассказчика.

**Почему именно так** (выводы исследования трендов, см. `research/sources.md`):
- Плоский векторный «научпоп» генераторы уже освоили, и он стал шаблоном.
- Растут тактильные «антиИИ» фактуры и процедурная анимация.
- Клише ИИ-визуала (светящиеся мозги, белые роботы, касание рук, «падающий код») сознательно исключены. Андроид появляется только там, где несёт смысл: статистика выпуска, «кукловод»-телеоператор.

**Удержание внимания:**
- Первые 30 секунд прямо подтверждают обещание названия: гипотеза → «впервые напечатано в 1863-м» → признание рассказчика.
- Ролик построен как цепочка вопросов: каждый ответ открывает следующий.
- Главы-«передышки» чередуются с ускорениями к кульминациям.
- Вкладки глав в углу кадра работают как навигация.
- Штампы «ФАКТ / РАСЧЁТ / ИНТЕРПРЕТАЦИЯ / ГИПОТЕЗА / СЦЕНАРИЙ / ПОЗИЦИЯ / НЕИЗВЕСТНО» делают видимой границу между данными и мнениями.

**Звук:**
- Партитура процедурная (`music.py`): минималистичная «процессная» музыка — фортепиано с войлоком, маримба, пэды, суб-бас. Паттерны нарастают нота за нотой: эволюция как накопление.
- Звуковые клише вроде тиканья часов, сердцебиения и тревожного «BRAAM» убраны.
- Шумовые эффекты (штамп, бумага, карандаш, рой частиц) сгенерированы ElevenLabs SFX.

## Как устроено производство

```
script/script.json        текст: что показывать (text) и что произносить (tts)
voice_local.py            озвучка: Piper ru_RU-denis + выравнивание слов через Vosk ASR
build_timeline.py         таймлайн, дорожка голоса, субтитры
assets/gen_shapes.py      процедурные «гравюры» → engine/stipple.py (стиплинг Ллойда)
engine/scenes.js          сцены; анимация привязана к словам озвучки
engine/render.js          покадровый рендер в headless Chromium → ffmpeg
music.py / make_cues.py / mix.py   музыка, разметка эффектов, сведение (−14 LUFS)
render_all.sh             параллельный рендер и сборка финального файла
```

Сборка с нуля:

```bash
python3 voice_local.py models/ru_RU-denis-medium.onnx <vosk-model-ru-0.42>
python3 build_timeline.py
python3 assets/bundle.py
node engine/dump_cues.js audio/scene_cues.json && python3 make_cues.py audio/scene_cues.json
python3 music.py audio/sections.json audio/music.wav && python3 mix.py audio/mix_cues.json audio/final_mix.wav
CRF=18 ./render_all.sh 4 out/naslednik.mp4
```

## Ограничения

**Голос.** Озвучка задумывалась голосом ElevenLabs (VASKO, модель v3). Месячная квота бесплатного тарифа (10 000 кредитов) закончилась после первого блока. Остальное озвучено локальной моделью Piper `ru_RU-denis-medium`. Её голос записан донором для датасета под лицензией CC0, но сама модель дообучена с английской модели lessac, у которой лицензия «только для исследований». Перед монетизацией ролика это стоит учитывать.

Голос Piper звучит заметно «машиннее», чем ElevenLabs. Концепции это не противоречит — рассказчик открыто синтетический, — но по качеству это компромисс.

**Как переозвучить.** Понадобится около 6 400 кредитов ElevenLabs. Порядок:
1. Сгенерировать шесть блоков из `script/script.json` (поле `tts`) голосом VASKO.
2. Нарезать их по репликам в `audio/voice/<id>.wav`.
3. Выполнить `voice_local.py … --realign`.
4. Пересобрать по шагам выше.

Анимация привязана к словам, поэтому синхронизация пересчитается автоматически.

**Иллюстрации.** Из-за дневного лимита бесплатного тарифа получилось сгенерировать только две исходные иллюстрации (андроид, рука с яйцом). Остальные формы нарисованы процедурно. Фигура человека получена из силуэта андроида.

**Проверка результата.** Ролик проверен по контактным листам (стоп-кадры каждые 6 секунд и на всех стыках сцен) и метрикам звука: громкость, спектр, распознаваемость речи. Прослушать его ухом я не могу. Разборчивость голоса проверена автоматическим распознаванием (Vosk ru-0.42): совпадение с текстом по репликам 83–100%, медиана 93%. Расхождения в основном приходятся на имена собственные и окончания.
